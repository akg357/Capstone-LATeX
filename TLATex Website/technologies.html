Languages and Document Tools

The main technologies involved in our product.
Technology Why we use it
TLA+ The specifications we are formatting are written in TLA+. Understanding the language helps us check that the output stays accurate.
Java / OpenJDK The existing TLATeX typesetter is written in Java. OpenJDK provides the tools needed to build and run it.
TypeScript The TLA+ VS Code extension uses TypeScript. We use it for changes to the extension’s export workflow.
LaTeX LaTeX provides the document formatting features that our project aims to use.
LuaLaTeX / MiKTeX LuaLaTeX compiles the document into a PDF. MiKTeX supplies the LaTeX tools and packages needed for that process.
tlatex.sty This style file controls parts of TLATeX’s output. We will update it for the requested formatting and symbol styling.

Development and Collaboration

Visual Studio Code

VS Code provides an editor for the project code and TLA+ specifications. The project setup includes the TLA+ extension, LaTeX Workshop, PDF viewing tools, and extensions for Java and TypeScript.

Git and GitHub

Git tracks our code changes. GitHub is used to share the code, manage branches, track issues, and review work before it is submitted to the sponsor.

Docker

Docker is used in our development setup to help run the tool in a consistent environment.

Live Share and Graphviz

Live Share is included in the proposed setup for remote collaboration. Graphviz Interactive Preview is included for viewing diagrams when needed.

Documentation and Website Tools

Our team uses Google Docs for written documents, Google Slides for presentations, and Canva for graphical designs. Documents are reviewed for consistent formatting before they are submitted.

This website uses plain HTML and CSS. Its styles and photos are stored with the website, so it does not need external fonts, scripts, or a running backend.
