Project Description

Making precise technical documents easier to read.

Our Sponsor

Our project is sponsored by SanDisk’s Tools & Infrastructure group. SanDisk wants technical documentation that clearly records how a system should behave.

When information is passed from one person to another, details can be lost or understood differently. SanDisk is interested in using TLA+ to describe systems with precise rules rather than relying only on written explanations.

What Are TLA+ and TLATeX?

TLA+ is a language for describing how a system works. It uses mathematical rules to make the expected behavior clear. Other tools can check those specifications for certain errors.

TLATeX is the typesetting tool. It takes a TLA+ specification and produces a TeX document. A LaTeX compiler then turns that document into a PDF.

The Problem

LaTeX has gained many formatting features over time, but TLATeX still uses an older approach to document styling. The resulting documents do not take full advantage of features such as color, embedded images, and more flexible formatting.

A specification can be precise and still be difficult to read. SanDisk wants the documents produced by TLATeX to be useful to the people reading them, as well as the people writing them.

Our Proposed Solution

We plan to update the TLATeX tool and its document styling. The proposed improvements include color, support for embedded images, improved mathematical symbol styling, and SanDisk formatting and fonts.

This work involves the TLA+ tools repository and the TLA+ extension for Visual Studio Code. We will also work with the tlatex.sty file, which controls parts of the document’s appearance.

Why It Matters

Clear formatting helps readers follow technical information. Images can explain ideas that are difficult to show with text alone, while consistent fonts and styling can make documents easier to use.

Our goal is to make TLA+ documentation easier to read and share without changing the meaning of the specification. Any time savings will need to be evaluated after the tool is developed and tested.
