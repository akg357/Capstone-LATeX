Planned Development Stages

This is a proposed sequence for the product work. Exact dates will be added after the team and sponsor confirm the schedule.

  1. Understand the existing tool

    Build the current tools, run sample specifications, and examine the generated output.

  2. Confirm requirements

    Agree on feature priorities and decide how each improvement will be checked.

  3. Design the changes

    Identify which parts of the Java code, style file, and VS Code extension need updates.

  4. Implement and review

    Develop the features in manageable pieces, review changes, and gather sponsor feedback.

  5. Test the output

    Check sample specifications, new formatting features, and the complete PDF export process.

  6. Prepare the handoff

    Finish the documentation, demonstrations, and code delivery for SanDisk.

Keeping the Project Moving

Our team meets weekly to review what was completed, discuss the next tasks, and assign responsibilities. We use GitHub issues to track development work.

At the first team meeting of each month, we review our progress, discuss challenges, and set goals for the next month.

Resources and Budget

The project requires computers with internet access, VS Code, OpenJDK, MiKTeX, and the supporting extensions. We also need access to the project repositories and sample TLA+ specifications.

No confirmed project budget is included in the materials currently available to the team website. Any approved costs will be recorded here.
