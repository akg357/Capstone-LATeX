Envisioned Solution

Updating the existing tool and the documents it produces.

Product Overview

Our product will be an updated version of the TLATeX document generation tool and its styling. We are building on the existing TLA+ tools rather than creating a separate specification language.

The goal is to let users turn their TLA+ specifications into documents with more useful formatting options.

From Specification to PDF

  1. TLA+ specification

    The user writes a specification describing how a system should behave.

  2. TLATeX

    The typesetter converts the specification into a TeX document.

  3. Document styling

    LaTeX styling controls how the specification, symbols, fonts, and other content appear.

  4. LuaLaTeX compilation

    The generated document is compiled into a PDF that can be read and shared.

Where Our Changes Fit

The Java typesetter

We will work with the TLATeX code in the TLA+ tools repository to support the requested document features.

The LaTeX style file

Changes to tlatex.sty will help control the appearance of the generated documents, including mathematical symbols and formatting.

The VS Code extension

We will work with the TypeScript code in the TLA+ extension where changes are needed to support the updated export process.
