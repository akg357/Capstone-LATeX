High-Level Requirements

The main improvements described in the project proposal.

Planned Features

These goals come from the sponsor’s project description. The final details and priorities will be worked out with the sponsor.

  • Color: add support for color in generated documents.
  • Images: allow images to be included in the document output.
  • Mathematical symbols: update styling through tlatex.sty.
  • Document appearance: support the formatting and fonts requested by SanDisk.
  • Tool integration: make the changes work with the TLA+ tools and the TLA+ VS Code extension.
  • PDF generation: produce documents through the LaTeX and LuaLaTeX workflow.
  • Project handoff: provide detailed documentation and a well-commented codebase.

Checking Our Work

As we make changes, we plan to check both the generated document and the export process. Formatting improvements should keep the specification’s content readable and preserve its meaning.

We will use sample specifications to check that TeX and PDF output can still be generated. New features will also need examples that show whether they work as intended.

Development Process

  1. Discuss the requested changes with the sponsor and define the work.
  2. Study the existing code and document generation process.
  3. Divide the work into GitHub issues and develop changes on branches.
  4. Review the code and test the generated output.
  5. Show progress to the sponsor and use the feedback to guide the next changes.
  6. Update the documentation and prepare the finished work for handoff.
